# نوبتیار (Nobatyar)

سیستم نوبت‌دهی خودسرویس برای مطب‌ها و درمانگاه‌های شیراز.

## هدف

- مطب/درمانگاه خودش ثبت‌نام می‌کند (فرم کوتاه).
- ادمین تأیید می‌کند.
- بیمار از طریق **وب‌سایت ساده** یا **ربات بله** نوبت می‌گیرد.
- پنل مطب: مشاهده نوبت‌ها، تعریف ساعات کاری و اسلات‌های خالی، تأیید/لغو نوبت.
- درآمد: اشتراک ماهانه (فعلاً فقط ساختار دیتابیس وضعیت اشتراک).

## محدوده فعلی (دامنه)

- فقط مطب و درمانگاه (نه بیمارستان)
- تمرکز اولیه روی شیراز
- بدون داده‌ی از پیش‌واردشده
- بدون اتصال واقعی به درگاه پرداخت (فقط فیلد وضعیت اشتراک)

## ساختار پروژه

```
nobatyar/
├── backend/          # FastAPI + SQLAlchemy + SQLite
├── frontend/         # صفحات وب (بیمار + پنل مطب + ادمین)
├── bot/              # ربات بله (اسکلت)
├── docs/             # مستندات
├── screenshots/      # مدارک بصری واقعی
├── tests/            # تست‌ها
└── README.md
```

## راه‌اندازی

```bash
cd backend
python3 -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
