# نوبتیار (Nobatyar)

سیستم نوبت‌دهی خودسرویس برای مطب‌ها و درمانگاه‌های شیراز.

## هدف

- مطب/درمانگاه خودش ثبت‌نام می‌کند (فرم کوتاه: نام، تخصص، آدرس، تلفن).
- ادمین تأیید می‌کند و حساب ورود پنل می‌سازد.
- بیمار از طریق **وب‌سایت ساده** یا **ربات بله** نوبت می‌گیرد.
- پنل مطب: مشاهده نوبت‌ها، تعریف ساعات کاری و اسلات‌های خالی، تأیید/لغو نوبت.
- درآمد: اشتراک ماهانه (فعلاً فقط ساختار دیتابیس وضعیت `active`/`inactive`).

## محدوده فعلی (دامنه — نگهبان دامنه)

- فقط مطب و درمانگاه (نه بیمارستان)
- تمرکز اولیه روی شیراز
- بدون داده‌ی از پیش‌واردشده
- بدون اتصال واقعی به درگاه پرداخت
- هیچ فیچر اضافی بدون تأیید صاحب پروژه اضافه نمی‌شود

## ساختار پروژه

```
nobatyar/
├── backend/          # FastAPI + SQLAlchemy + SQLite
├── frontend/         # صفحات وب (بیمار + پنل مطب + ادمین)
├── bot/              # اسکلت ربات بله
├── tests/
├── screenshots/
└── README.md
```

## راه‌اندازی

```bash
cd backend
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

سپس: http://127.0.0.1:8000

### حساب پیش‌فرض ادمین
- `admin` / `admin123`

## وضعیت فعلی — مرحله ۱ (تکمیل‌شده)

### آنچه ساخته شده و تست شده

1. **دیتابیس** طراحی‌شده برای صدها مطب (Clinics + WorkingHours + AvailableSlots + Appointments + Admins) با فیلد `subscription_status`.

2. **API کامل**: ثبت‌نام مطب، تأیید ادمین، ورود پنل مطب، ساعات کاری، تولید اسلات، رزرو نوبت، تأیید/لغو.

3. **وب‌سایت**: خانه، ثبت‌نام، رزرو بیمار، پنل مطب، پنل ادمین.

4. **ربات بله**: اسکلت آماده (نیاز به توکن واقعی).

5. **تست جریان اصلی**: همه مراحل از ثبت‌نام تا تأیید نوبت پاس شدند.
